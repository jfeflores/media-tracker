# Roadmap

Priorities favor data safety and daily usability without adding permanent dashboard clutter.

## Next

- Safe JSON restore/import with validation, duplicate/conflict preview, and an add-missing mode.
- Recoverable deletion and undo for frequent tracking changes.
- Complete browser/mobile/keyboard accessibility verification and fix confirmed issues.
- Split the large library/detail/editor component into domain components while preserving behavior.
- Dedicated standalone Cloudflare Access end-to-end deployment testing with an operator-owned test account.

## Daily quality of life

- Quick progress logging with undo.
- Pin, hide, or snooze Continue entries independently of status.
- Per-view sorting/density and compact dashboard preferences.
- Optional manual item ordering inside collections.
- Deep links and browser Back/Forward support for views and title details.
- Explicit metadata-match correction and duplicate review.

## Later, after the foundations

- Dated activity/rewatch history without inventing dates for old records.
- Media-specific progress for manga and games.
- Structured movie/game providers after API/license evaluation.
- Measurement-driven summary/detail payload splitting if library growth warrants it.
- Installable read-only/offline shell before considering queued offline writes.

Social feeds, engagement streaks, advertising, and unsolicited recommendations are outside the product's current focus. No roadmap item is a delivery promise.
